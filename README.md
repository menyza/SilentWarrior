# הלוחם השקט · AI Lab

אפליקציית הרגלים בעברית, מותאמת לטלפון, ללא תלויות התקנה.

## הפעלה

נדרשים Python 3 ו־Node.js לבדיקות.

```sh
cd /workspace/SilentWarrior
npm start
```

השרת מאזין בפורט 3000. לבדיקות: `npm test`.

## מה יש בגרסה

29 סעיפי מעקב מהטבלה המקורית, חלוקה לבוקר/יום/ערב, כל ההרגלים זמינים בלשוניות בוקר/יום/ערב ללא הפרדת עוגנים; מד הנקודות קומפקטי והניווט קבוע ורשימת ההרגלים נגללת בנפרד, סימון וביטול, 5–25 נקודות להרגל לפי חשיבות ומאמץ (5 × (חשיבות + מאמץ − 1)); מנוחה מתוכננת 10 נקודות, מד יעד יומי הניתן לשינוי (200 נקודות כברירת מחדל), יום מנוחה והיסטוריה שבועית הניתנת לתיקון. השמירה מתבצעת ב־localStorage של הדפדפן, לפי התאריך המקומי במכשיר.

## מגבלות

אין עדיין התראות, חשבון, גיבוי, סנכרון או תמיכה מובטחת ללא רשת. מחיקת נתוני האתר מוחקת את המעקב. ההרגלים קבועים בקוד; ניתן לשנות את יעד הנקודות אך לא לערוך את הרשימה בממשק. מטרות רפואיות או תדירויות נטילת תוספים לא נקבעות על ידי האפליקציה. אימון ומנוחה נחשבים סימון אחד; טרם הוגדר לוח אימונים שבועי.

כדי להשתמש באייפון מחוץ לסביבת הפיתוח נדרשת פריסה לכתובת HTTPS נגישה. כתובת localhost במחשב אינה נגישה מהטלפון. אחרי פריסה אפשר לפתוח ב־Safari ולבחור שיתוף ← הוסף למסך הבית.

עיצוב: CSS מקומי, עם גופן מערכת כגיבוי. אין צורך בשירות חיצוני להפעלת האפליקציה.

דירוגי החשיבות והמאמץ הם הצעה אישית התחלתית, לא הערכה רפואית. במסך ההרגלים מפורטים הדירוגים. הסימונים הקיימים נשמרים; הניקוד ההיסטורי מחושב לפי הדירוג החדש.

## התקדמות

דוח שבועי (ראשון–שבת) וחודשי, עם מעבר לתקופות קודמות, סך נקודות בתקופה ומאז ההתחלה, מספר ימים עם סימונים וטבלת 29 הרגלים מול תאריכים. הטבלה נגללת בנפרד עם שורת כותרת ועמודת הרגל קבועות. לחיצה על תאריך מאפשרת תיקון. רצף נוכחי ושיא נמדדים בכל ההיסטוריה עד היום, גם בצפייה בתקופה קודמת; אם היום טרם סומן, רצף המסתיים אתמול נשמר. מנוחה מתוכננת נחשבת רצף לאימון. ימים ללא סימון מפסיקים רצף מתועד. ימים עתידיים אינם נספרים.

ממשק הסימון מציג אריחי אייקונים בשלוש עמודות קומפקטיות עם שם קצר וניקוד. לחיצה על האריח מסמנת או מבטלת; כפתור פרטים מציג את שם ההרגל המלא והדירוג. הרגלים שסומנו נשארים במיקומם עם סימן ✓ וצבע השלמה. האפשרות ליום מנוחה נמצאת בחלון הפרטים של האימון. כל הרגלי חלק היום נכנסים ללא גלילה בגדלי המסך הניידים שנבדקו (320×568 עד 430×740); בהגדלת טקסט או במסך נמוך במיוחד נשמרת אפשרות גלילה כדי שלא להסתיר משימות.

השלמת הרגל מפעילה משוב נקודות ואנימציה קצרה. מוצגים עידוד לרצפים, חגיגת השלמת קבוצה וחגיגת יעד פעם אחת ביום (נשמרת במכשיר). ביטול סימון או עריכת ימים קודמים אינם מפעילים חגיגה. הגדרת הפחתת תנועה במכשיר מכבה את האנימציות ומשאירה את משוב הטקסט.

## מעקב משקל

לשונית משקל עם מדידה אחת לכל תאריך (ק״ג, ספרה אחת אחרי הנקודה), הזנת תאריכים קודמים, עדכון ומחיקה, היסטוריה מהחדש לישן והפרש בין שתי המדידות האחרונות. ללא יעד ירידה/עלייה או ניקוד. המדידות נשמרות ב־localStorage לצד ההרגלים, ללא גיבוי או סנכרון.
