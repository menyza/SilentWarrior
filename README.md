# הלוחם השקט · AI Lab

אפליקציית הרגלים בעברית, מותאמת לטלפון, ללא תלויות התקנה.

## הפעלה

נדרשים Python 3 ו־Node.js לבדיקות.

```sh
cd /workspace/SilentWarrior
npm start
```

השרת מאזין בפורט 3000. לבדיקות: `npm test`.

## מה יש בגרסה

29 סעיפי מעקב מהטבלה המקורית, חלוקה לבוקר/יום/ערב, כל ההרגלים גלויים ללא הפרדת עוגנים, סימון וביטול, 10 נקודות לסימון, מד יעד יומי הניתן לשינוי (200 נקודות כברירת מחדל), יום מנוחה והיסטוריה שבועית הניתנת לתיקון. השמירה מתבצעת ב־localStorage של הדפדפן, לפי התאריך המקומי במכשיר.

## מגבלות

אין עדיין התראות, חשבון, גיבוי, סנכרון או תמיכה מובטחת ללא רשת. מחיקת נתוני האתר מוחקת את המעקב. ההרגלים קבועים בקוד; ניתן לשנות את יעד הנקודות אך לא לערוך את הרשימה בממשק. מטרות רפואיות או תדירויות נטילת תוספים לא נקבעות על ידי האפליקציה. אימון ומנוחה נחשבים סימון אחד; טרם הוגדר לוח אימונים שבועי.

כדי להשתמש באייפון מחוץ לסביבת הפיתוח נדרשת פריסה לכתובת HTTPS נגישה. כתובת localhost במחשב אינה נגישה מהטלפון. אחרי פריסה אפשר לפתוח ב־Safari ולבחור שיתוף ← הוסף למסך הבית.

עיצוב: CSS מקומי, עם גופן מערכת כגיבוי. אין צורך בשירות חיצוני להפעלת האפליקציה.
